## 已确认的流程

1. 管理人员为本趟运输发专属入口，司机先确认车牌。车牌不符醒目提示并联系发件人重新发正确入口。
2. 运输前三类照片严格依次解锁：货运单 → 货物码放 → 装好的车厢。三项归档提交后进入运输。
3. 途中每次开门和关门均须拍照，包括卸货、检查及特殊情况。同一次开关门成组，可各有多张照片。
4. 额外问题随时记录，支持文字或照片。
5. 全部卸货后，司机明确确认“全部卸货完毕，完成运输”。关门不自动结束运输。
6. 重复打开入口接续本趟，不向司机提供往次运输提交入口或“找最新入口”。
7. 已提交必需类别的最后一张照片，必须补拍归档成功后再移除；纠正保留记录。
8. 空厢、温度等额外照片不作为默认缺项。
