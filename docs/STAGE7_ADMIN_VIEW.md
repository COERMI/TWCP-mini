# 阶段7：总部查看与本趟入口

日期：2026-11-22（北京时间）。仅使用已确认的专用测试环境，未发布生产。

## 总部查看批次

部署版本 `transport-v1-admin-1`，包含以下受管理员令牌保护的只读接口：

- `adminList`：新版/旧档案分源，车牌或档案编号文字搜索、状态、北京时间创建日期及分页。
- `adminWorkflow`：事件、照片各分页50项；前端核对revision，遇到司机更新则重取，避免拼接不同版本。
- `adminPhotoLinks`：检查照片所属内部档案ID、环境、归档目录及移除状态后签发查看链接。

Vue后台已有真实列表、详情、按事件分组翻图、原图/水印图切换、就地刷新链接、移除原因和取消记录。返回列表保留筛选及页码。旧档案保留旧分组，旧`success`只显示为水印待核验；没有写入或迁移旧数据。

## 创建与入口批次

后续版本 `transport-v1-admin-2` 在原接口上增补：

- 总部填写车牌、发货日期、方向和可选批次，创建独立运输。
- 发送前保存请求号和内容；响应未收到时保留原内容，刷新后继续用同一请求重试。
- 管理员可通过 `adminInvite` 找回**尚未领取且有效**的原入口。已领取的入口不重新发给其他司机。
- 发错车牌时，可停用尚未领取的入口。保存停用时间、更新版本及审计，档案保留；司机已确认后拒绝直接停用。
- 停用的新入口在列表和详情醒目标记。此前已停用的旧测试样本没有批量回填，读取入口仍由云端拒绝。
- 本机后台通过正常管理员令牌核对本趟后，可调用已安装微信开发者工具生成独立测试预览二维码。

预览工程为私有目录下`dispatch-phone-project`，既有`workflow-phone-project`、负责人原邀请及原二维码保持独立。二维码包含本趟入口能力，不加入公开证据或日志输出。页面明确标注测试预览，不能当作已发布的正式司机入口。

本批证据在 `evidence/2026-11-22/admin-dispatch-v1/`：本地105项通过，新增10项真实云端检查通过（创建一条TEST档案并停用其未领取入口；负责人既有手机测试运输仅读取）。真实浏览器另外创建一条TEST运输用于建档和二维码操作走查，详情见`browser-review.json`。

实际浏览器核对：草稿刷新后保留；建档后自动筛到该趟；重开原入口不新建档案；开发者工具编译成功，二维码在浏览器解码显示为470×470。中间发现工具将JPEG写入`.png`文件，已按真实字节识别格式，重试显示成功并增加回归用例。二维码及包含它的截图仅存私有目录，未将新邀请的扫码真机结果冒充已测。

## 本机后台与权限

本机启动：

```powershell
npm run build --prefix admin
node scripts/preview-admin.cjs
```

地址为 `http://127.0.0.1:4180/`。当前后台连接真实测试云，仍通过原管理员登录表单取得业务令牌，每个受保护操作由云端重新校验。无账号密码或签名密钥注入网页。桥接只监听本机，检查Host/Origin和请求大小，限制并行请求、登录失败次数和允许操作；不代理司机写动作。

当前环境Web匿名登录未启用，旧接口安全问题尚未全部修复，因此没有为了打开总部页面而放开整个环境。此本机桥接用于联调，不能直接部署到公网。公网认证、托管与正式小程序入口另行实施。二维码编译使用已授权开启服务端口的开发者工具，不上传发布版本。
