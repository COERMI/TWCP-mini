# 文件用途说明

更新日期：2026-11-22。覆盖本次Git非忽略清单中的242个文件；私人配置和本机照片不在此上传清单中。

## 给代码小白的读法

- 你日常只需要操作页面和阅读文档，不需要逐个修改代码。
- 想找某个文件，用搜索功能查完整文件名；下面按角色分组逐个列出用途。
- `.js/.cjs`是逻辑，`.vue`是总部界面，`.wxml`是微信页面结构，`.wxss/.css`是外观，`.json`是配置，`.md`是说明。
- “旧版”“原型”“试件”已经明确标出；它们存在不代表当前正在正式使用。
- 工具脚本可能写测试数据、图片或索引；不要因为名字有check/verify就自行运行。
- 上传GitHub只保存版本，不执行页面发布、云部署或数据迁移。

此表由`node scripts/update-file-guide.cjs`生成。开发人员新增文件时应补充用途映射再更新；命令只改本说明，不改业务数据。
