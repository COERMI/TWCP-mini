## 5. 数据、接口与异常恢复契约

沿用 `transport_records → transport_events → photo_records`，以文档 ID 建关系，车牌只用于查询；`counters` 负责分配业务编号。以下接口名为设计建议，实施前检查找回的版本有无等效入口。

1. **建档**。客户端为一次“开始新的一趟”生成稳定请求ID；服务端按微信身份和请求ID查重，分别返回原档案或创建新档案。主动再建一趟取得新请求ID。将旧 `status/submitted_at` 保留给旧端，增加独立基础提交状态。首版无需关闭整趟运输的操作。
2. **选择事件**。`beginEvent(record_id,type,operation_id)` 校验归属，固定任务按档案+类型唯一；动态事件按档案+操作ID唯一。并发分配同类型序号使用事务。事件ID在拍下一张时复用，空草稿不进入总部业务时间线。事件首次确认、序号、照片计数和取消策略要能在中断后恢复。
3. **提交照片**。按下“使用这张”时保存 `client_photo_id`、事件ID、首次设备时间、当次定位和原文件引用。服务端签发有归属的上传目标；同一张重试复用目标。按档案+照片请求ID唯一建记录，保存不可变原文件ID、派生图ID、接收时间、处理状态和失败原因；`original_url` 等旧字段实际存 fileID，临时访问链接只在读取时生成。
4. **一致性**。上传文件与数据库分两步，先保存待处理记录；水印文件用可预测且归属受控的内部键。写成功后用数据库事务将状态推进一次并更新计数。响应丢失后重查同一请求ID。文件已写、事务未提交时可重做关联；计数差异先出只读对账清单，孤立文件按保留期另行审批处理。限制输入字节、解码像素和单批数量，在处理前核对文件所属环境、对象键、上传授权及实际图片格式。
5. **旧数据**。先导出集合结构、索引、数量、文件清单和可恢复备份，在隔离副本演练恢复；检查重复档案号、重复事件编号、空令牌、孤立照片、计数差、缺双图。旧动态事件保持原分组，无法凭时间判断是否属于同一次开箱。旧水印质量标为待核验，旧提交记录保留原时间；不能据旧 `success` 批量推断水印合格。先上线兼容读，再加可选字段及新写接口，解决重复后才建唯一索引。回退优先恢复旧入口、暂停新写，保留新增数据；任何生产迁移单独提交影响范围、备份、回退和批准记录。

## 6. 水印实施决策与实拍门槛

优先验证**原图先归档、服务端异步生成水印**：后台取统一事件序号、同一份元数据，重试无需司机重拍。先在隔离云环境证明所选 Node 运行时、Sharp 二进制、字体授权与加载、中文渲染均可用；已有 Canvas 排版和测试作为备选。若服务端无法稳定运行，制作客户端 Canvas 双图试件，以同一测试矩阵比较耗时、清晰度及重试；客户端使用服务端分配的事件信息，明确记录生成端和版本。确定主方案后同步清单、页面、测试和发布文档。

- 原图保留相机交付的文件及方向信息。核对 `chooseMedia` 实际尺寸和压缩行为，实测需要时显式选择原图模式。派生图依 EXIF 旋转后再计算尺寸；长边限幅需结合运单放大辨字结果确定。普通照片使用局部半透明深底，首行车牌与事件、次行北京时间与星期，末行短地址和编号；长地址按像素折行，天气有可靠观测时附注。运单优先在照片下方扩展信息栏，保留全部单据像素。后台保留完整字段，勿挤压字体。
- 设备时间缺失保留空值，水印若采用服务时间须标明“服务器收到”；数据库使用日期/UTC时间点，显示统一 Asia/Shanghai。当前代码用 `Date.now()` 补设备时间，服务端时间在处理后写入；新实现分别记录首次接收、处理完成。地址解析失败但有坐标时显示坐标和精度；位置过旧、低精度或权限关闭均记录原因，允许继续上传。
- 天气通过服务端访问账户专属 API Host，分别核对路径、认证、经纬顺序、温度单位和响应字段。分开记录观测时间、查询时间、数据来源；延迟上传仅在匹配到拍摄地点和时段的观测时展示，否则标为不可用。历史查询能力和套餐需拿实际账户验证；历史日汇总不能充作拍摄时刻实况。只缓存时空接近的结果，设置超时，不让天气失败卡住归档。
- 状态至少区分原图待传、原图已收、水印处理中、水印失败、水印就绪。失败时保留原图并允许单独重做，只有产生真实派生图后才显示“查看水印图”。测试原图与派生图的归属、可下载性、清晰度和水印内容；仅比文件名或哈希不足以证明中文字形完整。
- 实拍覆盖 iOS、Android，各取横竖货物、细字运单、方向旋转、大图、小图与长中文地址。记录机型/微信版本、图片尺寸、原图与派生图大小、上传耗时、水印耗时、脱敏截图和请求ID。真机拒绝定位、拍完断网再移动、恢复重试、天气超时、云函数冷启动各跑一次。以司机能看清现场、总部放大能读运单、重试归属不变为放行条件。
